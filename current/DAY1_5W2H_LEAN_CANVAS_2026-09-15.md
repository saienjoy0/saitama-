# 1. 5W2Hに当てはめる

## WHY①｜なぜやるのか
### DAY1の問い
起業の動機・解決したい原体験・社会的意義

### 現在当てはめられるもの

**【現行方針】**

事業の教育目的は、子どもが自分の家を「小さな経済」として探索し、家計から仕事・企業・物価・税・金利・社会・世界の仕組みまでつなげ、数字と仕組みをもとに自分で判断できる範囲を広げること。

**【確認済み】**

現在の事業資料では、

- 日本では金融教育を受けたと認識する成人が少ない
- 金融教育の必要性を感じながら家庭で実践できていない保護者が存在する
- 実体験・判断・振り返りを使う教育設計には関連研究・既存実践がある

ことは比較的確認できている。

### 足りないもの

**【不足】創業者本人の「なぜ自分がこれをやるのか」が、現在の「家庭を小さな経済として探索する」案に合わせて一本化されていない。**

過去資料には原体験・金融への問題意識があるが、current/ の現在案に対して、どの原体験が直接この商品につながるのかは再整理が必要。

### 突き詰める問い

- なぜ「金融教育一般」ではなく「自分の家の経済を探索する」という方法なのか。
- なぜこの問題を自分が解くのか。
- 原体験から現在の商品まで、途中の飛躍なく説明できるか。
- 社会的意義と、顧客が実際にお金を払う理由を混同していないか。

## WHAT｜何を提供するのか／“不”をどう解消するか
### DAY1の問い
課題解決の方法・商品／サービスの具体内容と独自性

### 現在当てはめられるもの

**【現行方針】事業定義**

> 子どもが、自分の家を「小さな経済」としてゲーム感覚で探索し、家計がどう成り立っているかを理解する。そこから、お金・仕事・企業・物価・税・金利・社会・世界の仕組みまでつなげて理解し、自分で判断できる範囲を広げる教育サービス。

**【現行方針】MVPの中心テーマ**

> 「自分の家は、1か月どうやってお金で動いている？」

現在のMVP体験案：

1. 家が1か月にいくら必要か予想する
2. 親が公開可能な範囲で実際の数字を見る
3. 電気・食費・通信等から一つを選ぶ
4. なぜその金額なのか調べる
5. 改善・選択肢を考える
6. 必要なら実際に試す
7. 結果を見る
8. 背景にある社会の仕組みを一つ解放する

ゲーム性は、単なるポイント・バッジではなく、家の中に隠れている経済の仕組みを発見し、知識マップを解放していく方向。

**【不足】MVPとして実際にユーザーへ渡す「1回分の商品」の完成仕様。**

現在は体験の骨格はあるが、画面・冊子・Web・LINE等の提供形態、1回の所要時間、親の入力量、子どもの操作手順、1単元の終了条件までは確定していない。

# 4. 次に突き詰める順番

DAY1のフレームに沿うなら、今は機能追加より先に次の順で詰める。

1. **Problem / WHY：親が本当に何に困り、何なら払うか**
2. **Customer / WHO：最初の強い顧客と支払者は誰か**
3. **Solution / WHAT：子どもが実際に面白い1回分の体験は何か**
4. **Alternatives / +α：既存手段ではなぜ足りないか**
5. **UVP / Unfair Advantage：差別化が価値になり、さらに何が模倣困難になるか**
6. **Price / Revenue / HOW MUCH：誰がいくら払うか、成立する原価か**
7. **Channel / WHERE・HOW：埼玉で最初の顧客をどう獲得するか**
8. **Metrics：何をもってPoC成功とするかを数値化する**
9. **WHEN：利用頻度と2027年3月までの実行計画を固定する**

現時点では、特に1〜4を飛ばしてアプリ機能や細部を増やすべきではない。
