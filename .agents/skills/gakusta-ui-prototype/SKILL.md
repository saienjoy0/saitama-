# GAKUSTA UI Prototype Skill

## Purpose
Design prototype screens for GAKU∞STA before production implementation.

## Principles
- The product is not a quiz app. It turns family daily events into financial decision practice.
- AI does not give answers. AI asks, provides hints, and reduces support as the child improves.
- Child, parent, and grandparent views have different goals but share one design system.

## Required screens
1. Child journey
- discovery
- decision
- action
- reflection

2. Parent view
- observe decisions
- support without replacing judgment

3. Grandparent view
- return experience and questions

## Component rules
Create reusable components:
- DecisionCard
- AIHintCard
- ProgressMap
- FamilyMessage
- ReflectionCard

## Before production
Validate whether children want to repeat the experience before adding complex features or APIs.
