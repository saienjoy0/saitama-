## 2回目：画面と挿絵の一貫性、読み込みを整える

対象学年のtaglineがHero2のslotから表示されていなかったためpropへ修正。大きな日本語見出し、親子の場面、使う流れをファーストビューへまとめた。若葉色と生成りを主にし、濃い色は文字へ。未完成の操作見本であることは上部に明記する。

照明を分解しているように見える旧挿絵と「分解せず観察する」説明が一致していなかった。内蔵画像生成で、組み立てた照明を親子で観察し、ノートを指す場面へ編集。子どもの服は明るい若葉色。生成結果で照明の接続・顔・手・服を確認。保存先は `public/images/hero-observe-v3.png`、表示用は `hero-observe-640.webp` と `hero-observe-1280.webp`。元のPNGを保持。

最終プロンプト：同じ日本人の母親と小学校高学年の子ども、暖かい水彩の家庭・窓・木の机を保つ。照明はシェード・軸・台がつながった状態で机に立て、消灯し、子どもは観察ノートを指す。電気部品を外したり持ったりしない。服は#A4D76E系の明るい若葉色。顔・照明・指す手を中央80%に入れ、文字・UI・ロゴ・透かし・追加人物は入れない。使用方式：内蔵image_gen、参照画像からの編集。

既存sharpで幅別WebPへ符号化。4種類の最大幅合計412,580バイト、最小幅合計161,602バイト。前版PNGは9,327,644バイト。実測の速度やCore Web Vitalsではない。レビュー専用設定は折りたたみへ。回答を見直す一覧は、同じ質問を繰り返すウィザードから変更した。
