# 参考資料を確認してから改変する

2026-10-01。根拠となるユーザー指示：「すべての改変は参考する資料をまず見つけてから改変にしてください。」

この順序を、文言・質問票・体験の題材と数値・構成・画面・画像・アニメーション・コード・設計資料のすべての改変に適用する。

1. 変更する箇所と、解決したい問題を決める。
2. 関連する既存資料や参考事例を探し、使う箇所の本文・画面・動画を実際に確認する。
3. 出典、確認した箇所、今回への適用、変更対象、確認方法を記録し、改変前に短く示す。
4. その対応に沿って改変し、内容や表示・動作を確かめる。

関連する細かな変更はまとめて記録できる。既に読んだ資料が今回の変更を直接支える場合は再利用し、版と対象箇所を明記する。変わり得る価格・仕様・制度などは最新の原典を確認する。確認できない資料を読んだことにせず、根拠が不足する変更は不足箇所を示して保留する。

## 対象ごとの参考資料

| 変更対象             | 先に確認する資料                                                               |
| -------------------- | ------------------------------------------------------------------------------ |
| 題材・学習内容・金額 | 対象年齢に合う教材の原典、公式の商品・料金情報、現在有効な設計書               |
| 日本語・質問・回答例 | 最新の調査票と質問の目的、質問設計の原典、実際の日本語の使用例                 |
| 構成・画面・画像     | ユーザー指定の参考画面、関連する実例、画像・読みやすさ・アクセシビリティの資料 |
| アニメーション       | 実際に確認した動画・操作例、現在の役割別モーション仕様、動き低減の仕様         |
| コード・表示不具合   | 該当コードと再現した問題、採用したデザインや公式仕様・技術文書                 |
| 作業ルール・設計資料 | 最新のユーザー指示、既存の作業規約、変更対象の有効な資料                       |

参考事例の見た目は、教育効果・保護者の理解・申込率の証明ではない。資料が直接示す事実、そこからの設計上の判断、独自に作った仮の例を区別する。仮の価格や会話は仮例と分かるように表示し、実在の相場や利用者の声として扱わない。

## 改変前の記録

| 出典と版・確認日            | 確認した箇所                 | 今回への適用と限界       | 変更対象               | 確認方法                 |
| --------------------------- | ---------------------------- | ------------------------ | ---------------------- | ------------------------ |
| URLまたは既存ファイルのパス | ページ・節・画面・動画の場面 | 事実／設計判断／仮例の別 | 文言・画面ID・ファイル | 内容照合・表示・動作など |

既存の根拠記録を再利用する場合も、今回の変更対象との対応を先に確認する。この方針は改変の進め方を定めるものであり、承認済みの範囲を進めるたびに再確認を求める条件ではない。
