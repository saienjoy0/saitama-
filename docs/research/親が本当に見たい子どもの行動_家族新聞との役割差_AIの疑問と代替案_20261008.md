# 親が見たい子どもの行動／見たくない記録｜家族新聞と親向けインサイトの役割分離（2026-10-08）

**ステータス：外部調査・仮説比較。まだUI確定・本番実装ではない。** 対象は埼玉の小5〜6保護者（時間が足りない層の仮説）。直接の日本の小5〜6保護者にこのサービスの画面を見せた検証は未実施。ソースと主張を混同しない。

## 1. 問いと結論

「家族新聞＝みんなの思い出」と「親向けの行動記録＝何を見れば親が嬉しいのか」を混同しない。両方とも子本人の経験データから生まれるが、**編集の目的・出す情報・見せる人・次の行動**が異なる。

| 軸 | 家族新聞（共有済みの記事／任意の新聞号） | 親だけの行動インサイト（保護者向け） |
|---|---|---|
| 顧客ジョブ | 孫・子の近況、感動、一緒にした思い出を後で読み返す | 見ていない時の本人の判断・興味・挑戦を知り、次にどう接するか考える |
| 最初に見たいこと | その日の出来事＋写真＋本人の言葉 | ①子が何に取り組んだ ②重要な考え・工夫・戸惑い一つ ③親の対応が必要か |
| 詳細 | 物語、楽しかったこと、家族の感想 | 本人が選ぶまでの過程（比較、家族への質問、AIのヒントと本人の返答）、出所、確認状態 |
| 次の一歩 | 任意で「読んだよ」や思い出話 | 必要なら許可・報酬確認、そうでなければ**親子で一言話す提案**／見守り |
| 権限 | 子の共有希望・写真/本文の版・宛先を親が承認 | 本人に説明された範囲で保護者が確認。子の自由な非公開メモや全文音声は自動表示しない |
| 避ける | 家計・非公開発言・能力評定の自動掲載 | 子の人格・感情のAI診断、親による逐語監視、常時通知、親の追加宿題 |

**推論**：「親が嬉しい」は少なくとも3種類。A 自分が知らなかった子の一面、B 子が自分でやってみた工夫と考え、C 次にどこまで任せてよいかの具体的材料。すべてを一枚に詰めず、親自身が選んだ目的へ短い記事からアクセスする。

## 3. 親が見たいもの【検証仮説・優先順】

1. **親が見ていなかった具体的な判断**：「自分で店を調べて、迎えの時刻も聞き、A店へ選び直した」。子本人の見せたい範囲で、元発言に辿れる。
2. **昨日より出来るようになったと分かる実例**：両時点の記録がある場合に限り「前は買い物の前に聞かなかったが、今回は先に聞いた」。単日から成長認定をしない。
3. **本人の現在の関心／挑戦**：「いま何に興味がある」「自分で何をしたいと言っている」。性格・能力プロファイルや長期傾向をAIが推定しない。
4. **次にどこまで任せられるかの材料**：合意範囲、本人の行動報告、必要な助け。自動進級・「任せられる確率」を表示しない。
5. **親子で話すための一言**：親が何を聞けば子の話を広げられるか（根拠付き、任意、1案）。
6. **親に必要な確認**：実行・交換・公開など、実際に親の判断を要する内容。これ以外の親の作業は増やさない。

※この順位は**プロジェクトへの提案であり、保護者調査で順位が実測されたものではない**。

## 4. 親が見たくない／負担になり得るもの【研究からの注意＋仮説】

- **AIが決めた性格・金融能力・精神状態の断言**、独自の「判断力80点」。本人発言から内面を推定しない。
- **無意味な達成件数、滞在時間、ヒント回数、会話量**を自己目的化した監視表示。子の自立と対立し得る。
- 親も立ち会った内容を毎回長く反復した報告。**親にとって新しい価値がある一部分を示す**。
- 数十件のイベントログと全AIチャット。本文は読める短さ、根拠が必要な場合だけ詳細を展開。
- 常時の「ここが課題です」警告や通知。**本当に必要な承認や安全の判断**以外は静かな情報提供。
- AIの推論が本人の動機を誘導する言い方。「優しいから時間を考えた」は未発言なら不可。
- 家族の相談・秘密・家計・父母への不満の無断公開。子が話す前に閲覧範囲を説明する。
- 親が毎日子に質問しなければ記録が成立しない、新聞編集・コメント・褒め言葉のノルマ。

## 5. ユーザー案：『AIが疑問に思った点』のレビュー

### 採用したいところ
- 子の発言・行動に**まだ確かめていないこと**があれば、AIは「なぜ？」「ここはどう思った？」と聞き返せる（実際に子へ聞いた**イベントと返答**が記録された場合）。
- 親が子へ何を話してみればいいか分からない時、**具体的な元記録に基づく一問**を提案できる。
- 家族との会話を増やすきっかけが、学校アプリ的な監視報告とは異なる価値になる可能性。

### 反対するところ
- **AIが内心で何に疑問を感じたかの「思考実況」**を親が見たいとは裏付けられていない。AIの人格化・非検証推論・長文化の危険。
- AIの「疑問」が常に価値を持つわけではない。すでに子が説明済みなら不要。
- 子に実際に聞かなかったのに「AIはここが疑問でした／子はこう答えた」と記録するのは捏造。親に今から聞いてほしい提案なら**『会話のきっかけ（AI提案）』**と明記。
- 「AIがなぜ疑問を出した？」への説明はモデル内部の非公開推論ではなく、**『ここまでの本人の記録にこういう違いがあったため』**と元イベントを根拠に簡潔に伝える。Google PAIRの部分的説明に適合。

### 強い代替：情報を3種類に分ける
- **本人の事実**（必須）：「B店920円を見て、父の迎えの都合を聞き、A店980円を選んだと報告」。
- **本人の答えや試行錯誤**（記録があれば）：「AI『どうしてA店にしたの？』→はる『帰宅時間に間に合うから』」。AIが聞いた時はその記録を残す。
- **親が今度聞けるひとこと**（任意）：「次はB店に迎えに行ける日なら、またB店にすると思う？」。これは**AIが親へ提案した問いであり、子の疑問・回答ではない**。回答・家族の返信は親が強制されない。

## 6. UIパターン：新聞と親向けを同じ新聞記事にしない

### 親ホーム：新着カード最大1件
```text
🍛 はるちゃんが夕飯を準備したと報告   [親の確認待ち]
お父さんの迎え時刻を聞いて、店を選び直した
［どう考えたかを見る ›］
（確認依頼は独立したカード）
```

### 親向け詳細：「1分で背景が分かる」エピソード
```text
何をした／親がいま確認すること（先頭）
主な出来事：B店920円 → 父の迎えについて聞く → A店980円へ
本人の言葉：「帰る時間に間に合うから」
［出所：はるの発言、父の返答は本人が聞いたと報告］

[会話のきっかけ | AIからの提案・任意]
「はるに、時間以外に気にしたことがあったか聞いてみる？」
（親が興味がある場合だけ。子が言っていない回答は表示しない）

［詳しい経緯と元の記録を読む ▾］
［必要なら許可・実施・公開・報酬依頼の内容確認へ］
```

### 祖父母新聞：同じ元イベントから別編集
```text
🍛 4人分のカレーに挑戦
お迎えの時間を相談して、帰りに材料を買ったと話しました
［本人が公開を希望・親がその文章と写真を承認した場合のみ］
写真と一言／任意で祖父母からコメント
```

**注意**：親用エピソードも「AIが学びの成果を証明した」わけではない。記録された行動を正確に表す。

## 9. 実証しないと決められないことと面談案

この資料は**親が「何を見たくないか」の対象市場向け選好ランキングの実測ではない**。幼児研究・米国調査からの類推が中心である。**同じ日本の小5〜6家庭、特に共働きの保護者を直接観察する必要がある**。

**推奨：小5〜6の親6〜10人に、同じHSC-03の合成事実を以下の3バージョンで提示、提示順を入れ替え、親が言葉でどれを見たくなるかと実際のタップ・会話を観察する。**

- A **結果のみ**：「カレーを作った・40P確認待ち」
- B **判断の過程中心**：「B店→父へ相談→A店。本人の言葉」
- C **判断の過程＋AIの会話きっかけ1つ**：Bに「こう聞いてみる？」を任意追加

確認するのは、(1)知らなかった点を挙げられるか、(2)必要な確認を見つけられるか、(3)記事の根拠と本人報告の違いを理解したか、(4)自然に子と話したい／実際に話したか、(5)親の負担・押しつけ感、(6)子が親に見られる範囲を受容するか、(7)後日に保存・閲覧・有料継続したい理由。**「気に入った」の回答だけでは継続の証明にならない**。

また親に「完成した記事」と「実際の元発言」を見せ、**AIが勝手に何を足したと感じたか**を検証する。親子対話が既に十分な家庭と少ない家庭を混ぜて、セグメントごとの価値が変わるか確認。
