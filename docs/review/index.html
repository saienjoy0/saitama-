EXPERIENCE REVIEW / v0.4

ひとつの発見が、
家族の会話になる。

子どもは「試す」。親は「見守り、確かめる」。祖父母は「便りを受け取る」。目的の違う三つの画面を、同じ言葉・色・記録でつなぎます。

設計レビュー用の模擬画面です。ボタンは表示例を切り替えるだけで、保存・送信・AI処理は一切しません。

見本で操作できる範囲：水の問い4段階・共有辞退・親の確認／保留・祖父母の閲覧／任意返信・状態切替・M03。三役は独立した表示例で、相互に送信されません。別教材の選択、編集と再承認、写真、近況送信、設定・運営画面は仕様書でのレビュー対象です。

OSの動き抑制設定も尊重します。
