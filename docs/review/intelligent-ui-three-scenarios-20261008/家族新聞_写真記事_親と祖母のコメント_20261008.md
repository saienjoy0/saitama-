# 家族新聞「わが家のたより」編集設計（2026-10-08）

## 要旨
家族新聞は、クエスト報酬の台帳ではなく、子ども・親・祖母がそれぞれ関わる生活の出来事を写真と短い言葉で伝える。家族写真誌と新聞の中間。日付別アルバムから許可済み素材をまとめた号を任意発行し、毎回の手編集・コメントを強制しない。

## 外部調査で確認した事実
- Famileo（公式 https://www.famileo.com/famileo/en-US/ および https://www.famileo.com/famileo/en-EU/help ）：家族が写真と短文を投稿しA4紙面へ自動レイアウト。大きな写真と文字、年代順、表紙の写真モザイク、1～2枚程度の写真／ページが特徴。これ自体は本プロダクト需要の実証ではない。
- Neveo（公式 https://neveo.io/ ）：散歩、料理、日常の小さな出来事を月刊の写真誌へ。大事件も毎回のクエストも不要。
- MIXIの『みてね』利用者調査（2020） https://prtimes.jp/main/html/rd/p/000000058.000025121.html ：祖父母に写真を見返す・離れて見守る価値が報告された。対象と時期が限られ、この家庭の需要を保証しない。
- Google Photos共有アルバム https://support.google.com/photos/answer/9789702?hl=en ：共有先、コメント、追加者と権限を管理。

## 編集上の原則
1. 人物の顔・行動・関係性・生活の様子を優先。成果報告やポイント残高を表紙にしない。
2. 祖母は受信・レビューだけでなく、朝食・散歩・写真・短い近況の独立した投稿者。親は本人の言葉がある時だけコメントの寄稿者。
3. ある時だけ写真を使い、毎月の全員投稿を義務化しない。写真投稿＝公開許可ではない。
4. 紙面を編集しても子の非公開アルバム内容・家計の数字・アプリ内の承認情報は自動掲載されない。
5. 記事の人物名と引用には出所を持たせる。写真から行動達成や家族の感情を捏造しない。

## 表紙から中面までの紙面優先順位
- 第1面：新聞名・発行月→今月の1枚（祖母とはるの夕飯）→本人の選択理由→小さな家族のコメント。写真を最も大きく。
- 第2面：祖母の朝ご飯写真（祖母本人の寄稿）、祖母のレビューと親のひとこと、家族が承認した特典の約束券。ポスターのようなアイコンを増やさない。
- 写真が無い記事は文字と余白で成立させる。情報量に応じてテンプレートを3種類（大写真1枚／写真2枚／写真なし短文）使い分ける。
- 日付別アルバムと新聞号は同一素材を異なる表示にする。家族に二重入力をさせない。

## 報酬は交換段階を正確に見せる
- 依頼時は『お願いした』、親承認済・提供待ちは『交換が決まった、お出かけはこれから』、実施後のみ『家族で行ってきた』。
- ディズニーの例は家庭ごとの架空の約束であり、サービスがチケットを提供するものではない。実際のチケット画像・パーク公式ロゴやキャラクターを使用しない。
- 活動ポイントは事前合意→本人の報告→親の実行確認後に一度だけ確定。写真公開や祖母の返信とは独立する。

## 最優先のPoC
- 祖父母の『保存したくなる記事』は子の写真だけか、祖母も主役の紙面か。
- 親はコメントを必須にせずに寄稿・共有承認を続けられるか（確認にかかる秒数）。
- 子は本人の選択理由を家族に公開したいか、非公開を選べるか。
- 交換券の表記で『実施前と実施済み』を誤解しないか。
- 日付別アルバムだけで足りるか、月刊新聞号や印刷に追加価値・支払意思があるか。
