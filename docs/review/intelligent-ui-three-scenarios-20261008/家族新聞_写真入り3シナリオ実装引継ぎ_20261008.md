## 3本の記事

2. HSC-02 家の仕事を発見：見出し「夕飯は、料理の前から始まっていた！」。米・玉ねぎ・にんじんと買い物メモを考える写真。家族の仕事・二重買い→父に相談→出発前の在庫共有。**未確認のポイントを獲得済みにしない**。
3. HSC-03 おばあちゃんの夕飯：見出し「はる、夕飯の買い物に挑戦！」。祖母とカレーの食卓の大写真＋祖母本人が送った設定の鮭朝食写真。材料確認→4人分→A店980円／B店920円→帰宅16:45の約束と父の迎え→A店→必要な肉400g→調理・夕食。祖母のレビュー、保護者の感想、家族の特典『交換承認済み・お出かけはこれから』を追加。全て発表用架空設定。

## 閲覧と状態

- 祖母のホーム最新記事は写真サムネイル。『家族の新聞』には写真付き3記事が新着順で、祖母が当日投稿した記事も独立表示。『届いたアルバム』は3つから選び直せる。
- 本人・保護者の共有承認が済んだ『合成見本』だけをseedNewspapersで見せ、今プレイ中の子どもの非公開記録・sharePendingを祖母へ自動公開しない。
- 祖母の『今日も元気＋歩数』と『写真を送る』を残す。『読んだよ』重複防止と子どものワンタップ会話を残す。
- 写真は画像生成した架空の素材。写真は実行の証明ではない。祖母の歩数から安全や健康を保証しない。本番の権限・送信・同期・ポイント確定は別実装。
