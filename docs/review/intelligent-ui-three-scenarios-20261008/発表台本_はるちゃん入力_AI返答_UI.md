# 発表で見せる「はるちゃんの発言 → AIの返答 → UI」の完全台本

この台本は、2026-10-08現在の [presentation.html](./presentation.html) に組み込んだ**発表用の模擬応答**を、そのソースから取り出したものです。**実際のLLMの出力例ではありません**。本番の子どもとの会話実績でもありません。家族・価格・時刻などは合成例です。

## 何を見せるか

最初の画面は「今日のクエスト」「最初のサジェスト」「マイク」だけ。はるちゃんが話した直後、①はるちゃんの言葉を明示、②AIの返答を文字が現れる演出で表示、③返答と条件に沿ったUIカードを後から出す。家族に聞いて戻ったら、**新しい条件でAIの返答とUIが再構成される**。発表中に実マイクが不調なら右側のセリフボタンを使う。音声入力はブラウザー機能、以後は定義済みの規則とテンプレートを用いる。

## 発表での見せ方・説明の境界

- **最初に見せるのは会話**。AIが返す文章を読み上げる間に、画面下に必要な比較カードやヒントが現れることを示す。最初から全部のカードを出さない。
- **AIの支援は子どもの代行ではない**。家の在庫・家族の都合・実際の売り場価格は本人が調べる。提案を採用するか、自分で実行するかは本人の判断。
- **親子の約束**はAIの返答だけで成立しない。親が確認するまで未確定であり、実際の家庭の裁量権を自動で変更しない。
- **新聞**は、本人が報告した内容から文章の**下書き**を表示するだけ。本人が言っていない経験・学びを創作しない。家族への送信・祖父母への共有は未接続。
- **これはライブ生成AIのデモではない**。認識した発話に合う定義済みの画面部品と文章テンプレートを使い、リアルタイムに組み立てられたように見せる。審査員には「3つの代表シナリオを用いた体験プロトタイプ」と説明する。
- マイクでの認識処理はブラウザー提供元へ送信される場合がある。実児童の声や実家庭の個人情報を入力しない。発表では架空のセリフを使用する。
