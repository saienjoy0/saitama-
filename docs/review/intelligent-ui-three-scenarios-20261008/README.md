# 3シナリオを見せるIntelligent UI風デモ（2026-10-08）

目的は短時間で3つの場面を「動く体験」として見せること。製品エンジンの導入ではない。

## 開き方
**スマホで試す場合：** [外部HTMLプレビューで開く](https://htmlpreview.github.io/?https://github.com/saienjoy0/saitama-/blob/codex/three-scenario-intelligent-ui-demo-20261008/docs/review/intelligent-ui-three-scenarios-20261008/index.html)。この外部プレビューは第三者の中継サービスで、こちらでは実ブラウザ動作未確認です。実際の家族情報・個人情報は入力しないでください。表示されない場合はHTMLファイルを端末に保存してブラウザーで開きます。


[単体HTML](./index.html) をダウンロードしてブラウザーで開く。ビルド・APIキー・ログイン不要。画面左（スマホでは上）の3シナリオを選び、カードを押して先へ進む。「例文を入れる」は架空の音声認識を模した入力であり、手で直せる。「ヒントがほしい」を押すと補助が開く。最後に本人が選んだものと入力した内容だけがまとめカードへ出る。

再読込ですべてリセット。実際のAI、録音、保存、送信、決済、家族通知は行わない。

PR #11の製品Reactコードをコピーしたわけではない。意匠と導線を再利用し、今回は単体HTML/CSS/JSにまとめて依存をゼロにした。

## 外部でコピーできるUI部品
- [shadcn/ui Vite公式手順](https://ui.shadcn.com/docs/installation/vite)：本番Reactでカード・ボタン・入力を追加する時の第一候補。
- [assistant-ui Generative UI](https://www.assistant-ui.com/docs/tools/generative-ui)：本当にAIの出力とUIを結び付けたい段階の参考。今回は不要。
- [OpenAI ChatKit starter](https://github.com/openai/openai-chatkit-starter-app)：会話中心の独立UI。現在の製品全体への置換には使わない。

## 3シナリオと画面
| 代表場面 | UIの切替 | 子どもが現実にすること |
|---|---|---|
| HSC-01 初回 | 希望カード→家族の仕事→相談条件→次の一歩 | 自分の希望を親に伝えて、任せてもらえる範囲を合意 |
| HSC-02 調査 | メモ→聞き取り→家計の一部比較→改善提案 | 家族に質問し、未確認の部分を区別して一度試す |
| HSC-03 料理 | 在庫→価格比較→父への相談→時間と費用の再比較→売り場での単価→結果 | 現実で調べ、交渉し、自分で判断し、実行 |

## 重要な注意
- **固定の合成シナリオが状況別にUIを切り替えている「Intelligent UI風」デモ**。実際のモデル生成はない。
- 価格、家族、会話、達成した行動は全て架空。本人が発言していない理由や学びを記事へ補完しない。
- 子どもに生成文章を表示する安全条件を緩めたわけではない。実家庭データ、ライブ児童AI、リアルなマイク入力、送信・付与には別途設計と承認が必要。
- DESIGN／D90のまま、製品の実装許可は変更しない。これは合成レビュー用HTMLである。

## チェック
1. 3シナリオが完走する。戻る、再スタート、画面切替ができる。
2. 選択が必要な場面で勝手に自動決定されない。
3. ヒントを必要時に開閉できる。
4. 入力された文字は外部送信されず、HTMLとして解釈されない。
5. 320/360/390px・拡大文字・キーボードで見づらさがないか確認する。
