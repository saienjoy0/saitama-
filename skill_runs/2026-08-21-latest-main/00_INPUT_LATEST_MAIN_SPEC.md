# Input Snapshot — Latest Mainline Business Spec

Source: `今の進捗(2)(1).txt`
Status: mainline 正本; financial-literacy branch is intentionally excluded from this run.

## Fixed business purpose

Enable a child to move from receiving adult-created work toward independently noticing a situation, reasoning about what would help, proposing value, negotiating conditions, acting, seeing the result, reflecting, and eventually initiating without adult/AI prompting.

## Autonomy progression

choose → refuse → modify → negotiate → decide method → act → observe result → reflect → change approach → notice nearby problem → propose work → request things from parent/grandparent.

## Value definition

Value means a meaningful change for the recipient, including saved time, reduced effort, joy, information, shared experience, memory, or another fulfilled need. It is not limited to monetary productivity.

## Current learning mechanism

Use only enough scaffolding for the child to begin thinking, support the stuck part, avoid interfering where the child can act alone, fade support when capability appears, and transfer responsibility to the child.

Scaffolding research is used as design background only; the spec explicitly states that household problem-discovery effectiveness remains unproven and must be tested.

## Core loop

household situation → child notices / receives an entry point → interprets → thinks of an action → chooses/modifies/proposes → negotiates content/method/deadline/compensation → acts → recipient experiences value → concrete reaction + optional compensation → child decides how to handle money → reflects → family response/experience/new request → next action.

## Implementation hypotheses (not core)

- AI apprentice + household exploration
- support profile by cognitive step
- progressive hint ladder
- onboarding prompts that fade over time
- family newspaper / card / report formats
- specific UI names and interaction modalities

## Competition correction

The spec no longer treats child problem discovery, ingenuity, proposals, or reflection as uniquely ownable. Competitors already expose similar behaviors. Current differentiation hypothesis is the **systematic fading of only-needed support and transfer of control**, culminating in spontaneous action outside the app.

## PoC success definition

Treat these as an AND condition:

1. child wants another attempt;
2. combined AI + parent support decreases across repeated sessions;
3. child begins bringing a new real-life problem/situation without prompting.

A few initial sessions can show only a signal; they cannot prove durable autonomy development.

## Business questions kept separate

- Is the parent-side problem real and important?
- Can parent interaction stay light enough to continue?
- Does parent instruction also decline?
- Will a household repeatedly use it?
- Will anyone make a concrete paid continuation commitment?
- How does the business work if successful learning reduces product usage?
