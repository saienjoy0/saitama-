# GAKU∞STA「やってみクエスト」顧客Problem 外部ディープリサーチ

- 実施日: 2026-09-25
- 目的: 顧客インタビュー前に、外部公開情報だけで顧客Problemをどこまで確定できるかを見極める。
- 判断思想: FoundX「ユーザーインタビューの基本」に基づき、アイデアへの賛否ではなく、実際の生活・過去行動・既存解決策・残る不足を見る。
- 位置づけ: 既存の `research/` を読み直したうえでの差分調査。商品価値・需要・支払いを証明したものではない。

## 0. エグゼクティブサマリー

1. **「金融教育を必要とする家庭がある」「何を教えればよいか分からない保護者がいる」は、10家庭に再確認する必要性が低い。**
   Sony Bank 2025では、子どもがいる回答者2,110人中847人が家庭で金融教育を実施。未実施理由として「何を教えればよいか分からない」29%、「情報・教材がない」25%、「自身の知識不足」20%が挙がる。ただし銀行顧客サンプルであり全国代表値ではない。

2. **現在の中心仮説「親は何を教えるかより、どこまで本人に任せるかに困っている」は未証明。**
   家事・お手伝い領域には「自分でやった方が早い」「仕上がりが気になる」「失敗されるとイライラ」等の隣接証拠があるが、金融判断に直接外挿できない。

3. **FoundXの5問は、5問すべてを顧客に聞くという意味ではない。**
   外部情報でProblem候補・生活場面・代替手段の地図を作り、本人にしか分からない「最後の具体的出来事→対処→結果→残る不足」だけを聞く。

4. **外部調査で一般的生活場面はかなり把握できる。**
   2015年の「子どものくらしとお金」調査には、小学校高学年を含む児童のこづかい、使途、不足時の対応、貯蓄、電子マネー、ネット利用、家族会話、家事等が含まれる。

5. **ただし2015年調査は現在性が弱い。**
   2020年代のスマホ、ゲーム課金、キャッシュレス、EC等を補う必要がある。国民生活センターではオンラインゲーム関連相談・高額課金事例が確認できる。

6. **外部調査で弱いのは「既存手段を実際に使った後、なぜ止まったか」。**
   教材・アプリ・親子会話等の存在は分かるが、小5〜6家庭での利用後の不満・離脱理由を体系的に比較した強い資料は不足。

7. **やってみクエスト自体の価値はインタビューでは確定しない。**
   子どもが使う、再利用する、親負担が下がる、支援が減る、別場面に転移する、既存手段より選ばれる、支払う、は観察・PoC・実購入で見る。

8. **今の10家庭調査票は縮められる。**
   P01〜P08は実質5ブロック程度へ統合可能。P08と年収はコアから外し、F/Eは条件分岐、V/T1〜T3はPoCへ移す。

9. **外部調査は無限に続けない。**
   今後は「最新デジタル生活」「親課題の横比較」「既存サービス利用後の不満」「親子金融社会化」の4テーマに限定する。

10. **発表の証拠は“10人中○人が欲しい”ではなく、仮説→外部証拠→顧客行動→仮説変更。**
    一般論を再アンケートするより、未証明部分で何が覆ったかを示す。

## 1. FoundX 5問との対応

| FoundXの情報要求 | 外部情報で分かること | 証拠の強さ | 外部では分からないこと | 次の手段 |
|---|---|---|---|---|
| 顧客の一番の難題 | 「何を教えるか分からない」「教材・情報」「親の知識不足」は存在 | 中 | 対象家庭で何が最重要か。任せ方・時間・子の意欲との比較 | インタビュー |
| 最後に問題が起きる場面 | お小遣い、買い物、貯蓄、不足、家事、課金等の一般場面 | 中〜高 | その家庭で最後に起きた一件 | インタビュー |
| なぜ困難だったか | 親の知識・教材不足。家事では待てない/失敗が気になる等 | 中、任せ方は低 | 金融判断の場で何を恐れ、なぜ介入したか | インタビュー |
| 解決のために何をしたか | 親子会話、お小遣い帳、本、教材、講座等のカテゴリ | 中 | その家庭が何を選び、どこまで実行したか | インタビュー |
| 既存手段の何が不足か | 一部の仮説は作れるが体系的比較が弱い | 低〜中 | 実利用後の停止理由・残存課題 | インタビュー。製品比較はPoC |

## 2. Problem候補の比較

| Problem候補 | 外部証拠 | 証拠品質 | 現在の判定 |
|---|---|---:|---|
| 何を教えればよいか分からない | Sony Bank未実施層で29% | 中 | 存在はA。最重要かは未確定 |
| 教材・情報が見つからない/合わない | 25%が情報・教材不足を回答。一方無料教材は存在 | 中 | 「供給不足」ではなく発見・適合・実行の問題か要確認 |
| 親自身に知識・自信がない | 20% | 中 | 存在はA |
| どこまで本人に任せるか分からない | 金融領域の直接比較証拠は未確認 | 低 | C。現在の中核仮説だが未立証 |
| 親の準備・声かけ・見守りが重い | 隣接領域には示唆、金融教育の時間測定は不足 | 低 | C |
| 子どもが興味を持たない/続かない | 一般的ギャップはあるが主要因としての直接証拠は弱い | 低 | C/D |
| 知識教材を日常へ落とし込めない | 直接測る強い国内資料が不足 | 低 | C。価値仮説に近い |
| ゲーム・ネット課金等のデジタルトラブル | 国民生活センターに多数の相談・事例 | 高（存在） | Problem自体はA。GAKU∞STAが解くべきかは別 |
| 家庭の経済から社会を理解させたい | 教材領域は存在するが「強い困りごと」の証拠なし | 低 | Desired Outcomeの可能性。C |
| そもそも困っておらずnice-to-have | 未行動家庭が存在 | — | 必ず反証候補として残す |

### 重要な読み

現時点で外部証拠が最も強い親課題は「何を教えるか」「親の知識・情報」である。

一方、GAKU∞STAの特徴により近い
- どこまで本人に任せるか
- 実生活でやらせる親負担
- 教材から生活への変換

は事業仮説としては重要だが、外部証拠は弱い。

したがって、**強いところを10家庭へ再度聞くのではなく、弱いところを過去行動で確認する。**

## 3. A/B/C/D判定

### A｜外部調査で十分
- 子どもの金融教育に取り組む余地がある
- 金融教育を必要と感じる保護者が存在する
- 「何を教えればよいか分からない」親がいる
- 情報・教材不足を感じる親がいる
- 親自身の金融知識不足が障壁となる家庭がある
- 小5〜6がお小遣い・買い物・貯蓄等を経験する
- 小5〜6向けに金融テーマを扱う教材・学習機会が存在する
- 一般教育支出と世帯所得には関連がある
- デジタル課金等の消費者トラブルが実在する

### B｜追加外部調査で埋める価値あり
- 2026年に近い小5〜6のゲーム課金・キャッシュレス・EC等の実態
- 親課題を「内容・知識・時間・任せ方・子の意欲・継続」で横並び比較したデータ
- 顧客が実際に使う代替手段のカテゴリ
- 既存サービス利用者の一般的不満・離脱理由
- 親子金融社会化・お小遣い・自律の新しい国内研究

### C｜顧客本人の過去行動を聞く
- 小5〜6が最適な初期顧客か
- 「どこまで任せる」が本当に強い課題か
- 最近の具体的な一件
- 親が実際にどこで介入したか
- なぜ介入したか
- その家庭が最後に何を試したか
- 既存手段でどこまで解決したか
- Problemの実際のFrequency
- 親の実時間コスト
- 過去の実支出
- 中上流層がICPか
- 単身赴任・別居家庭が強いICPか
- 家庭経済を理解させたいことが強いProblemか
- 過去にどこまで家計情報を見せたか

### D｜観察・PoC・実購入
- T1/T2/T3のどれが刺さるか
- 子どもが説明なしで進められるか
- 子どもが実際に進めるか・再利用するか
- 親の手間が減るか
- 家族共有を使うか
- 共有が監視感を生まないか
- 祖父母の返信が次の判断を変えるか
- AI・親の支援量が減るか
- 別場面へ判断が転移するか
- J-FLEC＋生成AI＋LINE等より価値があるか
- 500円/1,000円等を実際に払うか
- 月額継続するか
- 本サービスの支払者
- CAC
- 運営サポート時間
- 長期金融リテラシー改善

## 4. 10家庭調査票の改訂判断

| ID | 判定 | 改訂方針 |
|---|---|---|
| P01 | 短縮 | この家庭の実行者・購入決定者・支払者のみ |
| P02 | 残す | 最後の具体的きっかけを1件聞く |
| P03 | 残す | 直近の本人判断を聞く |
| P04 | 短縮して残す | P03に直結して、親が何をしたか・なぜ・時間を聞く |
| P05 | 残す | 最後に実際に試した解決策 |
| P06 | P05へ統合 | 続いた/やめた、何が解決、何が残った |
| P07 | 条件付き | 実購入経験・実コストの補助確認 |
| P08 | 削除・統合 | P04/P05/P06の具体例で取る |
| 世帯年収 | コアから削除 | 明確な所得セグメント仮説を後で検証するときのみ |
| F01〜F03 | 条件付き・統合 | 別居家庭ICP仮説を残す場合のみ |
| E01 | 条件付きで残す | 家庭探索仮説の過去の自発行動を確認 |
| E02 | E01へ統合 | 何をした/どこで止まった |
| E03 | 残す | 過去の家計開示境界のみ。製品入力意思の証明にはしない |
| V01〜V03 | PoCへ | T3 Solution仮説でありProblem Interviewから外す |
| C01〜C05 | 短縮 | 子どもの過去行動のベースラインに限定 |
| T1〜T3 | PoCへ | 実際の行動で確認 |
| 体験後質問 | PoC | usability、親負担等 |
| 7日後 | PoC | 再利用・自発開始等 |
| 有料継続 | 実購入 | 仮想WTPを聞かない |

### 親Problem Interviewのコア5ブロック

1. **役割確認**
2. **最後のきっかけ**
3. **最後の子どもの判断＋親の介入**
4. **最後に試した解決方法＋結果＋残る不足**
5. **実コスト（時間・購入・申込み等。該当時のみ）**

## 5. 追加で必要な外部調査

今後の外部調査は以下に限定する。

### 最優先1｜2020年代の小学生デジタル生活
候補:
- こども家庭庁等「青少年のインターネット利用環境実態調査」
- 国民生活センター
- 消費者庁
- 近年の小学生白書

確認:
- スマホ
- ゲーム
- 課金
- 家庭ルール
- EC
- キャッシュレス
- 保護者管理

### 最優先2｜親課題の横比較
同一調査内で、
- 何を教えるか
- 親の知識
- 時間
- 任せ方
- 子の意欲
- 継続
を比較できる資料がないか探す。

### 高｜既存サービス利用後のfriction
App Store / Google Play等から、
- 続かない
- 親負担
- 子の拒否
- usability
- 記録/共有
- 課金
等をコード化する。

レビュー件数を市場比率には使わない。

### 高｜親子金融社会化の国内研究
J-STAGE、CiNii等で、
- お小遣い
- 親子会話
- 自律
- 親介入
- 金融自己効力感
を確認。

## 6. 外部調査の停止条件

- 同じ問いに独立した高〜中品質証拠が複数揃えばAへ。
- 本人の「最後の具体的行動」でなければ答えられないと判明したらCへ。
- 本商品利用後の行動でしか判定できないなら即Dへ。

Bを無期限に調べ続けない。

---

## 7. 次のアクション

1. 追加外部調査を「最新デジタル生活・親課題横比較・既存サービスfriction・親子金融社会化」の4テーマで短期的に閉じる。
2. その結果をEvidence Ledgerへ統合し、A/B/C/Dを更新する。
3. 10家庭調査票をv4へ削減。コアは5ブロック。
4. 最初の5家庭で、商品説明前に「Trigger → Problem → Action → Existing Solution → Gap → Cost/Frequency」を取得する。
5. 5家庭で一度止めてProblem/ICPを更新し、その後必要な追加家庭と2〜3家庭のPoCへ進む。

## 9. 最終判定

> **外部調査では「誰にどんなProblem候補があり、どんな場面・代替手段が存在するか」まで決める。**
>
> **インタビューでは「その人に実際に最後に何が起き、何を試して、何が残ったか」を取る。**
>
> **やってみクエスト自体の価値は、利用・再利用・比較・支払いで判定する。**

現時点で最大の危険は「調査不足」そのものではない。
**外部で分かる一般論を10家庭へ再度聞き、本当に未証明な任せ方・現行手段の残存課題・利用後行動・支払いを検証しないこと**である。
