# 発表デモ設計 / DEMO01

2026-09-23。基準: upstream aa4a4686ca302ef1ef14e139722b1802481ffae7。
本体の DESIGN/D90 を維持。ユーザーの明示依頼と PRESENTATION_DEMO_CODEX_PROMPT に基づく独立した合成デモ。旧HTMLは参考閲覧のみ、コード移植なし。

## 体験の核

「家族の暮らしが冒険になる」。ひとつの選択が本人の発見になり、家族の経験から次の問いが生まれる。

| 役割 | 目的 / 不安 | 画面・最初の成功 | コンテキスト |
|---|---|---|---|
| 子ども・はる | 自分で選ぶ / 宿題・採点にしたくない | 探検ルート→予想→比較の物差し→選択と理由→本人の発見カード | スマホ・投影。1画面1主操作 |
| 親 | 安心して任せる / 確認の山・公開ミス | 確認トレイで同じ版の理由と宛先を確認し承認または保留 | 合間に短時間。確認内容と操作の2列 |
| 祖父母・おばあちゃん | 孫の考えを知る / 小さい文字・返信義務 | 紙面形式のおたより→任意の経験・質問・応援 | 20px以上の本文、大きな操作 |

## 対応と範囲

F02/C01: 探検ルート。今回は買い物1題材のみ。他題材のダミーボタンなし。
F04/C02: 予想・比較（支払額/量/100ml/残額）・A/B/買わない・理由。
F05,F18/C02: 固定ヒントと模擬AI提案を明確に分離。手順 ID budget→compare→reason の固定カタログ。もっと小さく/ヒント/自分で/やめる。外部通信・疑似ロードなし。
F07,F08/C03,C04: 予想と本人原文を同じカードへ。共有先は親の確認後おばあちゃん。拒否は親にも非表示。
F09/P01,P02: 同じ版のカードを承認/保留。子の意思を親が上書きしない。
F10,F11/G02,G03: 一枚のおたより、経験/質問/応援/返信しない。
F12/C04: 出所付き返信→本人が選ぶ次の問い→具体的な次の一歩。返信なしでも進む。
F20: 文字100/200%、OSと本人の動き抑制、キーボード操作。

## 視覚・モーション

既存の意味トークンを維持: 本文 #172B2A、主操作 #176B5B、表面 #FFFDF7、補助 #EAF4F0。黄は発見のアクセント。子のルートは進捗を示す機能的な見取り図。親は静かな確認画面、祖父母は紙面。全役割にブランド・同じカード版・状態ラベル。
M01選択100ms、M02遷移180ms/最大8px、M04カードの強調1回、M05読書は移動なし、M07ヒント180ms。アニメ終了に依存しない。OSまたは本人設定で0ms。
見出しへのfocus、:focus-visible、48px/祖父母56px、PC16:9と390px。発表者バーに役割切替・リセット・表示設定を分離。

## 状態と失敗

useReducer の一時状態のみ。拒否/保留/返信/無返信の4分岐。承認は shared revision と一致する時だけ。撤回は承認・返信・派生たねを消す。役割切替は発表者のプレビュー操作で認証ではない。リロードとリセットで全消去。
通信・永続化が存在しないためネットワーク待ち/保存失敗を偽装しない。初期表示エラーは再読込の案内。依存導入後のオフラインローカル起動。効果・継続率・子の能力を表示しない。
