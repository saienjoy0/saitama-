## 開発・発表用起動

Node.js 22.13以上（検査時24.19.0）、npmを使用。

```bash
cd demo/presentation
npm ci
npm run build
npm run preview
```

`http://127.0.0.1:4173/` をChrome/Edgeで開きます。開発時は `npm run dev` → `http://127.0.0.1:5173/`。
依存導入にはネット接続が必要。導入後のbuild/preview、生成済みHTMLの表示はオフラインで可能。外部フォント・画像・AI/API・分析タグはありません。

検査：

```bash
npm test
npm run typecheck
# 以下はブラウザを利用できる環境で実行する最終確認
npx playwright install chromium
```

Playwrightはビルド済みプレビューを4173で起動し、PC1280×720とスマホ390×844を検査します。ポートを他アプリが使っていないことを確認。画像は `screenshots/automated/`、詳細は `playwright-report/`。ブラウザ依存の導入後はネット不要。

## 約100秒の発表操作と台詞

時間は台本上の目安。実測ではありません。投影は16:9、ブラウザ100%、上の発表者バーで役割を切り替えます。

| 目安 | クリック | 台詞 |
|---|---|---|
| 0–10秒 | 子ども → この探検をはじめる | 「子どもが日常の小さな判断を、自分で試すアプリです。今日は300円で飲み物を選びます。」 |
| 10–20秒 | Bを予想 → 比べてみる → 100mlあたり | 「大きいほうを予想しました。同じ量ならBが安い。でも、飲みきれるかや、残るお金も考えられます。」 |
| 20–35秒 | どう比べたらよい？ → もっと小さく → 自分で進む | 「困ったときだけ、考える手順を小さくします。将来の仮説は、子の困りごとを監修済み手順に対応づける支援。今日はその表示例で、実AI通信はありません。」 |
| 35–48秒 | Aを選ぶ → 選んだ理由へ → 飲みきれる量を選びたい → 発見カードをつくる | 「正解をAIが決めるのではなく、最後は本人が選び、理由を残します。」 |
| 48–60秒 | この内容を共有する → 発表者：親の画面へ | 「見せるかも本人が決めます。親は内容と宛先を確認するだけ。毎回、先生になる必要はありません。」 |
| 60–70秒 | この内容・宛先で承認する → 上部の祖父母 | 「承認した同じカードが、祖父母には大きな文字のおたよりになります。」 |
| 70–85秒 | 下へスクロール → 経験を伝える → この言葉を返す | 「祖父母は、自分の経験を返せます。返信しないのも自由です。」 |
| 85–100秒 | 上部の子ども → この問いを確かめたい | 「家族の経験から次の疑問が生まれ、本人が選んだ具体的な一歩につながります。教育効果はこれから検証します。」 |

この主経路ではBを予想してAを選ぶことで「自分の比較で選び直す」を見せます。飲み物の推奨や正解判定ではありません。

## 4分岐とリセット

| 分岐 | 操作 | 期待結果 |
|---|---|---|
| 非共有 | 発見カード → 共有しないで次へ | 親は確認0件、祖父母は新着なし。本人は次へ進める |
| 親が保留 | 共有 → 親 → いったん保留する | 親には同じ原文、祖父母には非表示 |
| 返信あり | 共有 → 承認 → 祖父母 → 経験/質問/応援 → 返す | 子に出所付き返信。本人が選んだときだけ次の一歩へ |
| 無返信 | 共有 → 承認 → 祖父母 → 今回は返信しない | 返信催促なし。子は自分で次の問いを選べる |

上部「最初から」→「リセットする」で記録・返信・選択・設定を消します。ページ再読込も全消去。共有後の子画面「共有を取り消す」で親・祖父母への表示、承認・返信・派生する問いを失効させます。

## 模擬・未接続の境界

- 全て架空。メモリ上のみ。実送信・実保存・購入・通知・決済・ログイン・家庭分離はありません。
- 役割切替は発表者用で、実際の権限制御を代替しません。
- AI提案は固定の手順IDと表示文。外部通信・疑似ロード・生成の演出なし。AIなしでも完走します。
- 返信例は架空の本人入力。家族の経験を事実認定しません。未返信や未操作から健康を推測しません。
- 共有しない場合、発表デモでは親にもカードを見せません（今回のプロンプトを旧仕様より優先）。
- 次の一歩まで実装し、2回目の体験記録や教育効果の検証はしていません。
- 比較値はA180円/200ml/90円毎100ml/残120円、B260円/400ml/65円毎100ml/残40円。
